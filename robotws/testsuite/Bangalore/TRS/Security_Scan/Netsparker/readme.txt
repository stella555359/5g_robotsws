Usage:

Option 1: Start Netsparker Scan with Build Download-Update with Mail
    sh start_scan.sh <build_release> <mplane_ip>

    Example: sh start_scan.sh SBTS00_ENB_9999_221224_000005 10.58.120.5

Option 2: Start Netsparker Scan
    python netsparker_scan.py --mplane <mplane_ip>

    Example: python netsparker_scan.py --mplane 10.58.120.5
