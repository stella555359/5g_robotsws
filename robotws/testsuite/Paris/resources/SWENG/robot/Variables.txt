*** Settings ***
Documentation
...     == Purpose ==
...     Module that describes global variables defined in SWENG and usable in robot test scripts.
...
...     == Description ==
...     Following libraries and keyword used in SWENG, several glabal variable are defined. These variables can be
...     used as variable or constante. The document presents the variables by library.


*** Keywords ***
Backup.robot
    [Documentation]
...     The global variables defined in library Backup.robot are defined in section '*** Variables ***'.
...
...     | *Variable*            | = Type = | *Value*  | *Description*                                                                                                       |
...     | ${ORI_EXT}            | Constant | .ori     |                                                                                                                     |
...     | @{SUITE_BACKUP_FILES} | Variable | list     | This list is setup in keyword 'Suite Backup Files' called by the keyword 'Suite Setup' from library Setup.robot. This list contents the list of backuped files.                                                                      |
    Log to Console     Global variables of Backup.robot

CallSetup.robot
    [Documentation]
...     The global variables defined in library CallSetup.robot are defined in section '*** Variables ***' except ${cell_nr}.
...
...     | *Variable*             | = Type = | *Value*    | *Description*                                                                                    |
...     | @{cell_nr}             | Variable |            | Is the number of 5G cells and is setup in keyword 'WTS Setup'.                                   |
...     | ${DEFAUT_THROUGHPUT}   | Constant | 2          | 2 Mbps                                                                                           |
...     | ${ENB_ID}              | Constant | 1          | By convention in the WTS configuration file, the node index corresponds to the eNB (4G) is 1.    |
...     | ${GNB_ID}              | Constant | 2          | By convention in the WTS configuration file, the node index corresponds to the gNB (5G) is 2.    |
...     | ${NO_THROUGHPUT}       | Constant | 0          | No throughput ==> 0 bps                                                                          |
...     | ${TARGET_CELLS}        | Constant | 1          | ?????                                                                                            |
...     | ${BASIC_UE_SA}         | Variable | dictionary | For more information see the CallSeup library documentation.                                     |
...     | ${UE_NO_PROFILE}       | Variable | dictionary | For more information see the CallSeup library documentation.                                     |
...     | ${UE_SIMPLE_TEST_MODE} | Variable | dictionary | For more information see the CallSeup library documentation.                                     |
...     | ${UE_SIMPLE}           | Variable | dictionary | For more information see the CallSeup library documentation.                                     |
    Log to Console     Global variables of CallSetup.robot

Tolology.robot
    [Documentation]
...     The global variables defined in library Tolology.robot are setup in keyword 'TOPO Read' called par the keyword 'Suite Setup' from
...     library Setup.robot. The these global variables are automatically defined if the keyword 'Suite Setup' or 'Suite Setup From Scratch'
...     is used as Suite Setup of robot script test.
...
...     | *Variable*     | = Type = | *Value*     | *Description*                                            |
...     | ${duplexMode}  | Variable | FDD, TDD    | Define the duplexe mode of radio interface : FDD or TDD. |
...     | ${isAic}       | Variable | True, False | = True if gNB is a vRAN NIC otherwise = False.           |
...     | ${isClassical} | Variable | True, False | = True if gNB is Classical otherwise = False.            |
...     | ${isDeploySA}  | Variable | True, False | = True if gNB is configured in SA otherwise = False.     |
...     | ${isSANSA}     | Variable | True, False | = True if gNB is configured in SANSA otherwise = False.  |
    Log to Console     Global variables of Tolology.robot
